# Rule 01 — Create plan

Đầu vào: `features/<TICKET-ID>/expect.md`, tài liệu nền và `01-create-plan.project-config.md`.

1. Kiểm tra AC, actor, input/output, state và ngoài phạm vi. Thiếu phần nào chỉ tạo draft nêu câu hỏi chặn.
2. Resolve service từ registry; không rõ thì hỏi.
3. Tạo `plan.md`, `tasks.md`, `impact.md` từ template.
4. Không code, không đổi feature sang `approved`, không tự ký Gate 1.
